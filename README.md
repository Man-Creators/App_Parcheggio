# Dov'è l'auto

App Android personale per ricordare dove ho parcheggiato. Grafica dal design system "Man".

- **Widget per la home** con il pulsante **SALVA** e l'ultimo parcheggio (toccalo per aprire la mappa)
- Mappa con il segnaposto, **Portami all'auto** (navigazione a piedi con Google Maps), condivisione
- Nota per ogni parcheggio (piano, colonna…), correzione della posizione trascinando il segnaposto
- Storico degli ultimi 50 parcheggi
- Scorciatoie tenendo premuta l'icona: "Salva parcheggio" e "Dov'è l'auto"
- Nessun servizio in background: il GPS si accende solo quando premi Salva

## Installare
Ogni modifica caricata su `main` viene compilata da GitHub Actions.
L'APK si scarica dalla pagina **Releases** (`DoveAuto.apk`).
